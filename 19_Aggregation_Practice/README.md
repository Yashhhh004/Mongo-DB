# 19 - Aggregation Practice Questions

Hands-on aggregation pipeline challenges solved with step-by-step logic and clear queries.

All practice queries run against the sample dataset in [`aggregation-practice.mongodb.js`](./aggregation-practice.mongodb.js).

---

## 📊 Sample Collections Overview

- **`orders`**: Contains customer orders with nested array of `products` (`name`, `category`, `price`, `quantity`), `city`, `paymentMethod`, and `status`.
- **`users`**: Contains registered user profiles (`_id`, `name`, `city`).
- **`orders2`**: Normalized orders containing `customerId`, `product`, and `amount`.

## 🎯 Practice Questions & Solutions

### Q1. Total Sales by Product Category
**Goal**: Calculate total sales revenue generated by each product category.
- **Pipeline Logic**:
  1. `$unwind`: Unpack the `products` array so each purchased item is its own document.
  2. `$group`: Group by `products.category` and compute total sales using `$sum` with `$multiply: [quantity, price]`.

```javascript
db.orders.aggregate([
  { $unwind: "$products" },
  {
    $group: {
      _id: "$products.category",
      totalSales: {
        $sum: { $multiply: ["$products.quantity", "$products.price"] }
      }
    }
  }
]);
```

### Q2. Top Customer by Total Spending
**Goal**: Identify the single highest-spending customer and see what items they bought.
- **Pipeline Logic**:
  1. `$unwind`: Flatten `products`.
  2. `$group`: Group by `customer`, accumulate purchased items into `details` using `$push`, and calculate `totalSpent`.
  3. `$sort`: Order descending by `totalSpent` (`-1`).
  4. `$limit`: Pick only the top 1 result.

```javascript
db.orders.aggregate([
  { $unwind: "$products" },
  {
    $group: {
      _id: "$customer",
      details: { $push: "$products" },
      totalSpent: {
        $sum: { $multiply: ["$products.quantity", "$products.price"] }
      }
    }
  },
  { $sort: { totalSpent: -1 } },
  { $limit: 1 }
]);
```

### Q3. List All Products Purchased by Each Customer
**Goal**: Consolidate and view all products bought by each individual customer.
- **Pipeline Logic**:
  1. `$unwind`: Unpack the `products` array.
  2. `$group`: Group by `customer` name and collect product objects into an array using `$push`.

```javascript
db.orders.aggregate([
  { $unwind: "$products" },
  {
    $group: {
      _id: "$customer",
      purchasedProducts: { $push: "$products" }
    }
  }
]);
```

### Q4. Filter High-Spending Customers (> ₹50,000)
**Goal**: Find all customers whose total order value across purchases exceeds ₹50,000.
- **Pipeline Logic**:
  1. `$unwind`: Flatten items.
  2. `$group`: Group by `customer` and calculate `totalSpent`.
  3. `$match`: Keep only groups where `totalSpent > 50000`.

```javascript
db.orders.aggregate([
  { $unwind: "$products" },
  {
    $group: {
      _id: "$customer",
      totalSpent: {
        $sum: { $multiply: ["$products.quantity", "$products.price"] }
      }
    }
  },
  {
    $match: {
      totalSpent: { $gt: 50000 }
    }
  }
]);
```

### Q5. Top 2 Best-Selling Products by Quantity
**Goal**: Determine the top 2 most popular items ordered based on total quantity.
- **Pipeline Logic**:
  1. `$unwind`: Unpack items array.
  2. `$group`: Group by `products.name` and sum their `products.quantity`.
  3. `$sort`: Order descending by quantity (`-1`).
  4. `$limit`: Restrict to top 2 products.

```javascript
db.orders.aggregate([
  { $unwind: "$products" },
  {
    $group: {
      _id: "$products.name",
      totalQuantity: { $sum: "$products.quantity" }
    }
  },
  { $sort: { totalQuantity: -1 } },
  { $limit: 2 }
]);
```

### Q6. Pagination Using `$skip` and `$limit`
**Goal**: Implement clean API page-based pagination in an aggregation pipeline.

```javascript
const page = 1;
const limit = 5;
const skipDocs = (page - 1) * limit;

db.orders.aggregate([
  { $skip: skipDocs },

]);
```

### Q7. Average Order Value (AOV) per City
**Goal**: Find the average order value in each city (two-level aggregation).
- **Pipeline Logic**:
  1. `$unwind`: Flatten items.
  2. First `$group`: Group by `{ city: "$city", orderId: "$_id" }` to calculate the total price of each unique order.
  3. Second `$group`: Group by `city` and compute `$avg` of the order totals.

```javascript
db.orders.aggregate([
  { $unwind: "$products" },
  {
    $group: {
      _id: { city: "$city", orderId: "$_id" },
      totalOrderValue: {
        $sum: { $multiply: ["$products.price", "$products.quantity"] }
      }
    }
  },
  {
    $group: {
      _id: "$_id.city",
      avgOrderValue: { $avg: "$totalOrderValue" }
    }
  }
]);
```

### Q8. Comprehensive Category Analytics
**Goal**: For each category, compute total quantity of items sold, total revenue, and average revenue per transaction.

```javascript
db.orders.aggregate([
  { $unwind: "$products" },
  {
    $group: {
      _id: "$products.category",
      totalQuantitySold: { $sum: "$products.quantity" },
      totalRevenue: {
        $sum: { $multiply: ["$products.price", "$products.quantity"] }
      },
      avgRevenuePerItem: {
        $avg: { $multiply: ["$products.price", "$products.quantity"] }
      }
    }
  }
]);
```

### Q9. Join Collections Using `$lookup`
**Goal**: Combine normalized orders with corresponding customer details from the `users` collection.

```javascript
db.orders2.aggregate([
  {
    $lookup: {
      from: "users",
      localField: "customerId",
      foreignField: "_id",
      as: "userDetails"
    }
  }
]);
```

### Q10. Find Inactive Users (Users with Zero Orders)
**Goal**: Detect all registered users who have never placed any order.
- **Pipeline Logic**:
  1. `$lookup`: Join `users` with `orders2`.
  2. `$match`: Filter for users whose joined `orders` array is empty (`{ $eq: [] }`).

```javascript
db.users.aggregate([
  {
    $lookup: {
      from: "orders2",
      localField: "_id",
      foreignField: "customerId",
      as: "orders"
    }
  },
  {
    $match: {
      orders: { $eq: [] }
    }
  }
]);
```
